# نظام كوبونات ميركل للصنايعية

موقع كامل لحملة **Merkel electric**: الصنايعي يسجّل أكواد الكوبونات وصور الفواتير، الموزع يراجع ويوافق مبدئيًا، وإنت (الأدمن) بتعمل الموافقة النهائية.

النظام **مش محتاج أي برامج إضافية** غير Node.js. قاعدة البيانات ملف واحد (SQLite مدمجة في Node)، ومفيش `npm install`.

---

## ١. اللي محتاجه

- جهاز أو سيرفر (VPS) عليه **Node.js نسخة 22.13 أو أحدث** (يُفضّل 22 LTS أو 24).
  - اتأكد بالأمر: `node -v`
  - لو مش متسطّب: نزّله من [nodejs.org](https://nodejs.org) (اختار LTS).

## ٢. التشغيل لأول مرة

1. فك ضغط الملف وادخل على الفولدر:
   ```bash
   cd merkel-coupons
   ```
2. شغّل الموقع:
   ```bash
   npm start
   ```
3. أول مرة بيشتغل، هيطبع **اسم مستخدم وكلمة سر الأدمن** في الشاشة، وهيحفظهم كمان في الملف `data/ADMIN-PASSWORD.txt`.
4. افتح المتصفح على:
   - صفحة الصنايعي: `http://localhost:3000/`
   - لوحة الموزع: `http://localhost:3000/distributor`
   - لوحة الأدمن: `http://localhost:3000/admin`
5. ادخل لوحة الأدمن، وروح **الإعدادات** وغيّر كلمة السر، وبعدين **امسح** ملف `data/ADMIN-PASSWORD.txt`.

> عايز تختار اسم مستخدم وكلمة سر الأدمن بنفسك من الأول؟ شغّل أول مرة كده:
> `ADMIN_USER=ahmed ADMIN_PASS='كلمة-سر-قوية' npm start`

## ٣. خطوات تشغيل الحملة

1. **الإعدادات:** اتأكد من قيمة الكوبون (٦٠٠٠ ج)، عدد الكوبونات للجايزة (٥)، اسم الجايزة (شنيور)، وتاريخ انتهاء العرض. واكتب **رابط الموقع** الحقيقي (مثلاً `https://coupons.merkel.com`) عشان يتطبع في QR الكوبونات.
2. **الموزعين:** ضيف كل موزع (الاسم، المنطقة، الموبايل، اسم مستخدم إنجليزي، كلمة سر).
3. **الأكواد:** من صفحة الموزع اختار عدد الأكواد (مثلاً ٢٠٠) واضغط **ولّد الأكواد**. كل كود بيتربط بالموزع ده.
4. **الطباعة:** اضغط **طباعة الكوبونات**، هتفتح صفحة A4 (١٠ كوبونات في الورقة) فيها الكود و QR. اضغط "اطبع" أو احفظها PDF وابعتها للمطبعة. وفي كمان ملف **CSV** بالأكواد لو المطبعة عايزاه.
5. سلّم الكوبونات للموزع، وابعتله اسم المستخدم وكلمة السر بتاعته.

## ٤. إزاي بيشتغل

**الصنايعي (من غير حساب):**
- يفتح الموقع أو يصوّر QR الكوبون، يكتب اسمه ورقم موبايله والأكواد، ويرفع صور الفواتير.
- ممكن يسجّل الأكواد على مرات، كلها بتتجمّع على رقم موبايله.
- لما يتجمّع **٥ أكواد صالحة من نفس الموزع** على نفس الرقم، الطلب بيتعمل أوتوماتيك ويروح للموزع صاحب الأكواد.
- يتابع طلبه من صفحة **متابعة طلبي** برقم الموبايل.

**الموزع (بحساب):**
- يشوف طلبات صنايعيته بس، بالأكواد وصور الفواتير.
- يعمل **موافقة مبدئية** أو رفض.
- يقدر **يدخّل أكواد نيابة عن صنايعي** (لازم تكون من أكواده هو).
- بعد موافقتك النهائية، يسلّم الشنيور ويضغط **تم التسليم**.

**الأدمن (إنت):**
- **الموافقة النهائية** على الطلبات (تقدر كمان توافق على طلب الموزع لسه ماراجعهوش).
- تقارير: الشنيورات المتوافق عليها والمتسلّمة، عدد الفواتير، الأكواد المستخدمة، المشتريات المحققة، وأنشط موزع.
- استعلام عن أي كود: مين سجّله وإمتى وفي أنهي طلب.
- تنزيل كل الطلبات كملف CSV يتفتح في Excel.

**قواعد الأكواد:**
- كل كود بيتسجّل **مرة واحدة بس**. النظام بيرفض الكود المستخدم أو الغلط أو المكرر.
- الأكواد مش فيها حروف بتتلخبط (O و 0 و I و 1 و L)، والصنايعي يقدر يكتبها بحروف صغيرة أو بأرقام عربي أو من غير الشرطة.
- لو طلب اترفض، أكواده **مبترجعش** تتسجّل تاني (حماية من التلاعب).
- لو وقّفت حساب موزع، أكواده اللي لسه متسجّلتش مبتتقبلش.

## ٥. التشغيل على سيرفر حقيقي

### إعدادات اختيارية (متغيرات بيئة)

| المتغير | الاستخدام | الافتراضي |
|---|---|---|
| `PORT` | رقم البورت | `3000` |
| `HOST` | العنوان | `0.0.0.0` |
| `TRUST_PROXY` | اكتب `1` لو الموقع ورا Nginx/Caddy | فاضي |
| `COOKIE_SECURE` | اكتب `1` لو الموقع شغّال HTTPS | فاضي |
| `DATA_DIR` | مكان قاعدة البيانات | `./data` |
| `UPLOAD_DIR` | مكان صور الفواتير | `./uploads` |

### خليه يشتغل على طول (حتى لو السيرفر عمل ريستارت)

أسهل طريقة بـ **pm2**:
```bash
npm install -g pm2
TRUST_PROXY=1 COOKIE_SECURE=1 pm2 start npm --name merkel -- start
pm2 save
pm2 startup
```

### HTTPS ودومين

لازم الموقع يكون على **HTTPS** لأنه فيه كلمات سر. أسهل حاجة **Caddy** (بيعمل شهادة SSL لوحده). ملف `Caddyfile`:
```
coupons.example.com {
    reverse_proxy localhost:3000
}
```
وشغّل الموقع بـ `TRUST_PROXY=1 COOKIE_SECURE=1`.

## ٦. النسخ الاحتياطي (مهم)

كل البيانات في فولدرين بس:
- `data/` (فيه `merkel.db`: الموزعين والأكواد والطلبات)
- `uploads/` (صور الفواتير)

خد نسخة منهم كل يوم. لنسخة سليمة من قاعدة البيانات والموقع شغّال:
```bash
sqlite3 data/merkel.db ".backup 'backup-$(date +%F).db'"
```
أو وقّف الموقع شوية وانسخ الفولدرين.

## ٧. ملاحظات

- الـ QR في صفحة الطباعة بيتعمل من مكتبة على الإنترنت، فلازم الجهاز اللي بتطبع منه يكون متصل بالنت. لو الـ QR مظهرش، الكود نفسه مطبوع والصنايعي يكتبه بإيده.
- لو غيّرت عدد الكوبونات للجايزة، التغيير بيأثر على الطلبات الجديدة بس.
- أقصى حجم لصورة الفاتورة ١٠ ميجا، ولحد ١٠ صور في المرة.
